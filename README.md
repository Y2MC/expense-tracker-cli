# Expense Tracker CLI

Command-line expense tracker built with Python

## Features

- Add new expenses (description + amount)
- View all expenses
- Show total amount spent
- Delete expenses
- Data is automatically saved to a file and loaded when the program starts

## How to Run

1. Make sure you have Python 3 installed
2. Open a terminal in this folder
3. Run:

```bash
python tracker.py
python3 tracker.py
```
